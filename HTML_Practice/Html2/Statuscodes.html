HTTP Methods

HTTP methods define the actions to be performed on resources on a server. Here are the most common methods:

  • GET : Retrieve data from the server.

  • POST : Send data to the server to create a resource.

  • PUT : Update an existing resource or create if it doesn't exist.

  • DELETE : Remove a resource from the server.

  • PATCH : Partially update a resource.

  • HEAD : Retrieve metadata (headers) about a resource without the body.

HTTP Status Codes

1xx: Informational

  • 100 : Retrieve data from the server.

  • 101 : Server switching protocols as requested.

2xx: Success

  • 200 : Request succeeded, and response contains the resource.

  • 201 : Resource successfully created.

  • 204 : Request succeeded but no content to return.

3xx: Redirection

  • 301 : Resource has moved permanently to a new URL.

  • 302 : Resource temporarily at a different URL.

  • 304 : Resource not modified; client can use cached version.

4xx: Client Errors

  • 400 : Request malformed or invalid.

  • 401 : Authentication required or failed.

  • 403 : Server refuses to fulfill request.

  • 404 : Requested resource not found.

  • 405 : HTTP method not allowed on this resource.

3xx: Redirection

  • 500 : Generic server error.

  • 501 : Server does not support the method.

  • 502 : Invalid response from upstream server.

  • 503 : Server temporarily unavailable.
